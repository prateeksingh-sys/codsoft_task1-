Spam Classifier

A machine learning-based Spam Classifier that automatically detects whether a message is spam or legitimate (ham).

Features
Text preprocessing and feature extraction
Machine learning-based classification
Spam/Ham prediction
Model evaluation using standard classification metrics
Tech Stack
Python
Pandas
NumPy
Scikit-learn
Jupyter Notebook / Google Colab
Usage

Run the notebook, provide a message as input, and the trained model will classify it as Spam or Ham.
